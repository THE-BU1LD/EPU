# E7 publication gates

Prepared package verification is engineering evidence. Publication claims stay
blocked until every applicable gate below has retained evidence.

- Run on an admitted CUDA GPU with Internet off and retain the Kaggle version URL.
- Download the complete output archive and verify every manifest and source hash.
- Replay all raw records into reported metrics, intervals, permutation p-values,
  Holm adjustments, hypothesis decisions, and the negative control.
- Report every failed or negative hypothesis without removal or retuning.
- State that the official train/test split is writer-disjoint while row-level
  writer identities are unavailable and intervals are not writer-cluster-adjusted.
- Obtain an independent reproduction against the same frozen source identities.
- Audit every manuscript claim against the verified evidence and its limitations.
